# NLP Service

Микросервис для парсинга текстовых напоминаний с использованием GigaChat API. Сервис извлекает структурированные данные из неформатированного текста на естественном языке: дату и время, приоритет, категорию, сложность задачи и дополнительные заметки.

## Возможности

- **Парсинг текстовых напоминаний** - извлечение структурированных данных из естественного языка
- **Интеграция с GigaChat** - использование AI для анализа текста
- **Валидация данных** - автоматическая проверка и корректировка извлеченных данных
- **Обработка дат** - автоматическое определение времени напоминания из текста с учетом московского времени
- **REST API** - простой HTTP интерфейс для интеграции с другими сервисами
- **Обработка ошибок** - graceful degradation при ошибках парсинга

## Требования

- Python 3.8+
- GigaChat API ключ и scope
- Установленные зависимости из `req.txt`


## Запуск

### Разработка (с автоперезагрузкой)

**Установите зависимости:**
   ```bash
   pip install -r req.txt
   ```

**Создайте файл `.env` в корне проекта:**
   ```env
   GIGACHAT_AUTH_KEY=your_auth_key_here
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   APP_HOST=0.0.0.0
   APP_PORT=8000
   DEBUG=false
   TZ=Europe/Moscow
   ```

**Запустите:**
```bash
python -m app.main
```

Или через uvicorn напрямую:
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

После запуска сервис будет доступен по адресу: `http://localhost:8000`

## API Endpoints

### `POST /parse`

Основной эндпоинт для парсинга текста напоминания.

**Request:**
```json
{
  "text": "Напомни завтра в 10:00 позвонить маме",
  "user_id": "50789519"
}
```

**Response:**
```json
{
  "user_id": "50789519",
  "text": "позвонить маме",
  "remind_at": "2025-11-14T10:00:00+03:00",
  "complexity": 1,
  "priority": "medium",
  "category": "личное",
  "notes": null
}
```

**Поля ответа:**
- `user_id` - ID пользователя, отправившего запрос
- `text` - извлеченный текст задачи (без временных указаний)
- `remind_at` - дата и время напоминания в формате ISO 8601 (московское время)
- `complexity` - сложность задачи (1-5)
- `priority` - приоритет (`low`, `medium`, `high`)
- `category` - категория задачи (`работа`, `личное`, `здоровье`, `покупки`, `другие`)
- `notes` - дополнительные заметки (опционально)


### GigaChat API

Сервис использует GigaChat API для анализа текста. Для работы требуется:
- **Auth Key** - ключ авторизации (получить в [кабинете GigaChat](https://developers.sber.ru/))
- **Scope** - область доступа (обычно `GIGACHAT_API_PERS`)
